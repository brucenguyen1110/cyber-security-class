## Key areas being researched

* Security challenges in multi-tenant cloud environments.
* ML for threat detection, prevention, and prediction.
* Blockchain for data integrity, audit trails, and authentication.
* TEE for secure isolation and sensitive data processing.
* Integration of ML, Blockchain, and TEE into an adaptive framework.
* Comparison with traditional security approaches and a systematic literature review.

## Cloud adoption creates major security and privacy risks.

* Traditional security measures are often inadequate for dynamic threats.
* ML, Blockchain, and TEE each address different security needs.
* Their integration can provide a more holistic and proactive posture.
* Compliance and auditability are important cloud security concerns.

## Open questions

* The framework is conceptual; empirical validation and real-world deployment remain open.
* Practical trade-offs in scalability, performance, and cost need further study.
* Cross-industry generalization and standardized implementation are unresolved.
* Automated remediation, predictive threat modeling, and long-term effectiveness need future research.
